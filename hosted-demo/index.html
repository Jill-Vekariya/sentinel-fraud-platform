About the hosted version

This hosted demo runs the project's trained classifier and anomaly model in your browser. It works independently of your computer's Docker services.

Simulated inputs are labelled synthetic. Transactions, account history and reviewer feedback are stored in this browser. This version has no server-side ledger, Kafka processing, Redis cache, SHAP endpoint or automated retraining.

The downloadable Docker project contains the full streaming reference implementation. Neither version is a production payment system.
